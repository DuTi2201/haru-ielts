# Destination B1 course (bank `b1`)

42 lessons, one per unit of the book, generated by `build.py` from the text files in this folder.

| File | Holds |
| --- | --- |
| `grammar_a..d.txt` | the 28 grammar units: cards, key words, questions, sentences to build, a speaking task |
| `vocab_units.txt` | the 14 vocabulary units: goal, where it pays off in IELTS, a speaking task |
| `topic_vocab.txt` | topic vocabulary per unit, with Vietnamese meanings |
| `phrasal_verbs.txt`, `prep_phrases.txt`, `word_patterns.txt`, `word_formation.txt` | the four other trays of a vocabulary unit |
| `unit_assignment.json` | which vocabulary unit each tray item belongs to (written by `assign_units.py`) |

    python3 scripts/b1/build.py
    python3 -c "from app.services.lesson_seed import load_all; b = load_all(); print(len(b.lessons), b.problems)"

What is taken from the book is its syllabus: unit titles, page numbers and word lists. Explanations,
examples, questions and model answers are written for this course. Each lesson sends the learner
to the book for the book's own exercises.
